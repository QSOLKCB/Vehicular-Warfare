# VW-001A simulation contract

Run `node --test test/authority.test.js` from the repository root. Run `node tools/measure.mjs` for a complete cold-start mission trace, per-tick timings in microseconds, actor/projectile counts and replay receipt. No installation is required with Node 22 and Python 3.

The mission input is a plain record with one uint32 seed, or the same JSON in at most 128 characters. The only accepted control input is an integer bitmask. A run ends within 21,600 ticks and retains at most one command change per tick, 32 live shots, three bodies and 96 recent events. Replay verifies the whole event stream and terminal state with non-cryptographic FNV-1a checksums. SHA-256 identifies the simulation source. The state checksum uses JS number serialization. Replay equality is scoped to the same source and runtime.

The terrain uses the pinned Heightfield's two triangles per cell, including the diagonal crossings. Its maximum measured planar gradient bounds the height difference under a horizontal disc. Sweeping the centreline with the hull half-height plus this gradient times hull radius gives a conservative continuous clearance test. This deliberately leaves extra space below the aircraft on level ground. Contact arrests the craft, and excessive inward normal velocity destroys it. The skids, tail and animated blades are visual details outside the gameplay hull. Collective drives lift, bank and pitch redirect it, and assisted hover cancels vertical drift over time. World edges and ceiling limit travel.

AA needs 120 consecutive visible ticks, the convoy 240. Losing sight clears acquisition immediately. Each guard keeps its last observed point for 180 hidden ticks, counts down without updating that point, and must acquire from scratch when the aircraft reappears. Projectiles already in flight continue. Within a forward cone, visible targets receive aim assistance at launch. Shots then fly straight for at most four seconds. Earlier terrain contact takes priority over equal-time actor contact. Sixteen rockets, two hits per objective, and four enemy hits per aircraft make the mission finite. A spent magazine loses only after the last player shot resolves. Two destroyed opponents yield 200 points and victory.

## Engine provenance

RIDGEFIRE originally shipped against engine v3.4.0 at `0cffbcfe2524bbf7f82190ef8ef0813aeb6bb466`. The current approved engine v3.5.0 has identical bytes for every module used by the simulation. Use `python3 tools/identity.py --check` to verify the existing source receipts. [Current pin, import closure and reproduction](ENGINE_BASELINE.md)

The terrain, math and moving-segment collision APIs supply the numerical primitives. Flight exports a rigid-body integrator, while this mission uses a bounded assisted-rotor model. Trajectory and sensing query box geometry. The game also needs exact triangular terrain intersections. Combat3D advances timers and projectiles at 1/60. Cockpit-rig, scenic3d, render-webgl, render-lit, world-vis and render-packing provide presentation APIs. The RGB renderer and box stream use six floats per vertex, distinct from the 11-float lit layout. All gameplay geometry, controls and mission data are original.

## Long Watch and Frostline Run

The original limits above describe Sable Valley. The two additional built-in mission IDs select a 288 × 960 m heightfield with 36 × 120 cells. The roster is immutable mission content. Long Watch has nine opponents across four relay sites. Frostline has fifteen across six crossings. Each route ends within ten minutes. A ground unit needs unobstructed sight within 116 m for 120 consecutive ticks (84 for a scout) to open fire. Scouts move laterally, take one rocket hit, and share the carrier's slower firing interval. Route rounds deal 12 damage. All types use the same sweep and terrain masking rules as Sable Valley.

The current sector must be cleared and physically visited within 18 m of the beacon, at most 34 m above sampled terrain. Long Watch requires 360 uninterrupted ticks in the zone. Frostline accepts a fly-through. A confirmed visit restores the 16-round magazine and up to 32 hull points. All units are present from mission start. Off-route kills count and beacons advance in order. Legacy Sable Valley receipts from the original release are accepted only when both checksums reproduce.
